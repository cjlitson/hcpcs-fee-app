## ✨ Application overview

### CMS sync and data handling
- Sync CMS DMEPOS fee schedules for selected states/years.
- Multi-strategy CMS URL discovery with fallback logic.
- Local SQLite storage for quick lookup.
- CSV import support for manual or previously downloaded files.

### Search, filtering, and ZIP pricing
- Filter by year, state, HCPCS group, HCPCS code, and keyword.
- Enter ZIP code to apply rural (R) vs non-rural (NR) pricing context.
- View effective allowable values in the main table.

### History and comparison
- Open HCPCS history from the main table.
- Review multi-year pricing history.
- Compare state pricing side-by-side in history view.

### Purchase List workflow
- Build a Purchase List from results, quick-add, or context actions.
- Save/load reusable bundles.
- Keep pricing aligned with a specific selected CMS year and state.
- Generate worksheet-oriented document output for downstream use.

### Exports and documents
- Main results export: CSV, Excel (.xlsx), PDF.
- Purchase List document generation and workflow-friendly outputs.

### User experience
- Dark mode support.
- Desktop installer and shortcut workflow.
- In-app update notifications/actions.
- Backup/restore support.

## 📥 Download and install (Windows)

| File | Description |
|---|---|
| **`HCPCSFeeApp-Setup.zip`** | ✅ Recommended package (installer + app files) |
| `HCPCSFeeApp.exe` | Standalone executable option |

### Install
1. Download **`HCPCSFeeApp-Setup.zip`** from the release assets.
2. Extract it.
3. Run **`Install.bat`**.
4. Launch from the desktop shortcut.

Install location: `Documents\HCPCSFeeApp\` (per-user install). No admin rights required.

---

## 🔄 Updating

- If a newer release is detected, the app can show an in-app **Update Now** flow when running the installed executable.
- Manual fallback: install the newest `HCPCSFeeApp-Setup.zip` by re-running `Install.bat`.

## 🐛 Notes / limitations

- The executable is not code-signed; Windows SmartScreen may warn on some systems.

- CMS site/file naming changes may require app updates if sync discovery patterns change.
