## 📥 Download and install (Windows)

1. Download **`HCPCSFeeApp-Setup.zip`** from this release.
2. Extract the ZIP.
3. Run **`Install.bat`**.
4. Launch from the desktop shortcut.

Install location: `Documents\HCPCSFeeApp\` (per-user install, no admin rights required).

---

## 🔄 Updating

- **In-app update:** use the update banner’s **Update Now** action from the installed EXE.
- **Standalone updater flow:** the app exits, updater progress is shown, then the updater downloads, replaces, and relaunches the app.
- **Manual fallback:** download the latest setup ZIP and run `Install.bat`.
- **Diagnostics:** updater logs are written to `%TEMP%\HCPCSFeeApp_update.log`.
