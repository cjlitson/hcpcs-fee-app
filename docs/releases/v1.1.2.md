## 🆕 What's New in v1.1.2

This release focuses on making the in-app self-update flow reliable for end-to-end testing, plus UI and document-generation polish carried forward from v1.1.1.

### In-app updater — hardened Windows handoff

The **Update Now** self-update flow received a significant reliability overhaul for packaged Windows EXE scenarios:

- After the original process exits, the helper script now waits an additional 2 seconds for Windows to fully release the file handle before attempting any file operations.
- The old exe is explicitly deleted first (up to 10 retries × 1 s) before the rename step, eliminating the most common cause of silent move failures.
- The rename/move of the new exe into place is retried separately (up to 5 retries × 2 s).
- Existence of the final exe is verified before relaunching.
- Every major step is now logged with a timestamp to `%TEMP%\HCPCSFeeApp_update.log`:
  - Helper started
  - Waiting for PID / Process no longer detected
  - Waiting for file handles to release
  - Attempting to remove old exe / retry counts
  - Renaming new exe into place / retry counts
  - Replacement verified
  - Relaunch command issued / Helper finished
- On failure, the log now includes explicit **MANUAL RECOVERY INSTRUCTIONS** so users can complete the update by hand.

### UI and document workflow polish (carried from v1.1.1 work)

- **Deliver To field** in the document-generation workflow now includes an **Other** option with a free-text entry box for non-standard delivery destinations.
- **Year notice** in the Purchase List panel is displayed in red when the selected year may not match the current CMS release year, so the context is immediately visible.

## ✨ Application overview

### CMS sync and data handling
- Sync CMS DMEPOS fee schedules for selected states/years.
- Multi-strategy CMS URL discovery with fallback logic.
- Local SQLite storage for fast offline lookup after sync.
- CSV import for manual or previously downloaded files.

### Search, filtering, and ZIP pricing
- Filter by year, state, HCPCS group, HCPCS code, and keyword.
- Enter a 5-digit ZIP code to apply rural (R) vs non-rural (NR) pricing context automatically.
- View effective allowable values in the main table based on current ZIP and year.

### History and comparison
- Open HCPCS history from the main table.
- Review multi-year pricing history.
- Compare state pricing side-by-side in the history dialog.

### Purchase List workflow
- Build a Purchase List from results, quick-add, or context menu.
- Save/load reusable bundles.
- Keep pricing tied to a specific selected CMS year and state.
- Year context displayed in red when it may not match the current CMS year.
- Generate worksheet-oriented Word/PDF documents for downstream use.
- Deliver To options include standard locations and a free-text **Other** field.

### Exports and documents
- Main results export: CSV, Excel (.xlsx), PDF.
- Purchase List document generation (Word worksheet format).
- Copy workflow-friendly output for email/procurement steps.

### User experience
- Dark mode support across key dialogs and workflow areas.
- Desktop installer and shortcut workflow.
- In-app update notifications and hardened **Update Now** self-update flow.
- Startup splash / loading progress.
- Backup/restore support.

## 📥 Download and install (Windows)

| File | Description |
|---|---|
| **`HCPCSFeeApp-Setup.zip`** | ✅ Recommended package (installer + app files) |
| `HCPCSFeeApp.exe` | Standalone executable option |

### Install
1. Download **`HCPCSFeeApp-Setup.zip`** from the release assets.
2. Extract it.
3. Run **`Install.bat`**.
4. Launch from the desktop shortcut.

Install location: `Documents\HCPCSFeeApp\` (per-user install). No admin rights required.

## 🔄 Updating

### In-app update (recommended for installed EXE users)
When a newer release is detected on startup, an update banner appears at the top of the window.
Click **Update Now** to:
1. Download the new `HCPCSFeeApp.exe` next to the current one.
2. Launch a detached helper script and exit.
3. The helper waits for the app to fully exit, removes the old exe, renames the new one into place, verifies it, and relaunches the app.
4. Every step is logged to `%TEMP%\HCPCSFeeApp_update.log` for diagnostics.

### Manual update
Download the latest `HCPCSFeeApp-Setup.zip` and re-run `Install.bat`.
