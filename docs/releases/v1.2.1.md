## ✨ Application overview

- Sync CMS DMEPOS fee schedule data and store it locally for fast lookup.
- Search and filter by year, state, HCPCS group/code, keyword, and ZIP-based rural/non-rural pricing context.
- Build and manage Purchase Lists with quantity/pricing context tied to selected year/state.
- Save/load/manage bundles for recurring workflows.
- Export results to CSV, Excel (.xlsx), and PDF.
- Generate worksheet-style procurement documents from Purchase List data.
- Use in-app update detection and **Update Now** from installed EXE deployments.

## 📥 Download and install (Windows)

1. Download **`HCPCSFeeApp-Setup.zip`** from this release.
2. Extract the ZIP.
3. Run **`Install.bat`**.
4. Launch from the desktop shortcut.

Install location: `Documents\HCPCSFeeApp\` (per-user install, no admin rights required).

---

## 🔄 Updating

- **In-app update:** installed builds check GitHub releases and show **Update Now** when a newer version is available.
- **Update Now flow:** downloads `HCPCSFeeApp_new.exe`, launches `HCPCSFeeAppUpdater.exe`, exits the app, performs in-place replacement (with backup/retry fallback when needed), and relaunches.
- **Manual update:** download the latest setup ZIP and run `Install.bat` again.
- Diagnostic updater logs are written to `%TEMP%\HCPCSFeeApp_update.log`.
