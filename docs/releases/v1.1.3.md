# 🎉 v1.1.3 — Public Release for Updater Validation

**VA HCPCS Fee Schedule Manager**  
*WSNC IMPACT Team*

> This lightweight public release advances versioning after the internal/test 1.1.2 build so installed 1.1.2 users can validate end-to-end in-app updating.

---

## 🆕 What's New in v1.1.3

- **Improved Windows in-app updater reliability:** the hardened **Update Now** handoff/replacement flow from 1.1.2 is now published in a newer release so updater detection and replacement can be validated end to end.
- **Export and worksheet/document improvements:** current export options and worksheet-style document generation remain aligned with the latest workflow and wording improvements.
- **Purchase List / builder refinements:** Purchase List year/state pricing context, document-builder behavior, and delivery-destination handling (including **Other**) remain up to date.
- **Documentation and guidance refreshes:** release-facing docs have been polished so users landing on this release get accurate current-product install/update guidance.

---

## ✨ Application overview

- Sync CMS DMEPOS fee schedule data and store it locally for fast lookup.
- Search and filter by year, state, HCPCS group/code, keyword, and ZIP-based rural/non-rural pricing context.
- Build and manage Purchase Lists with quantity/pricing context tied to selected year/state.
- Export results to CSV, Excel (.xlsx), and PDF.
- Generate worksheet-style procurement documents from Purchase List data.
- Use in-app update detection and **Update Now** from installed EXE deployments.

---

## 📥 Download and install (Windows)

1. Download **`HCPCSFeeApp-Setup.zip`** from this release.
2. Extract the ZIP.
3. Run **`Install.bat`**.
4. Launch from the desktop shortcut.

Install location: `Documents\HCPCSFeeApp\` (per-user install, no admin rights required).

---

## 🔄 Updating

- **In-app update:** installed builds check GitHub releases and show **Update Now** when a newer version is available.
- **Manual update:** download the latest setup ZIP and run `Install.bat` again.
- Diagnostic updater logs are written to `%TEMP%\HCPCSFeeApp_update.log`.

---

## 🖥️ System requirements

- Windows 10 or Windows 11
- Internet required for CMS sync and release/update checks
